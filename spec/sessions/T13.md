## Decisions / interpretations
- Hook + overlay instead of one component; `onAction` returns the `BuilderResult` so the UI shows inline errors.
- Delete prompt lists only "hard" dependents (slab, agregacija left with < 2 components, specijalizacija); veze are removed silently.
- Removing a podtip so that < 2 remain deletes the specijalizacija after confirmation.
- A constraint without a domain is dropped; a constraint on a non-last item of a comma line splits the line.
- participantIndex indexes the IR participant list (slab/spec: 0 = nadređeni/nadtip).
- History is cleared when switching to Tekst; the editor is not mounted in Interaktivno.
- Interaktivno compiles with 0 ms debounce. Mapping-name editing is in the edge popover only (no "empty spot" target).
- Extra strings: `Komponente moraju biti različiti elementi.`, `Element je već komponenta.`, `Preslikavanje`, `Ime`, `Kardinalnost`.
