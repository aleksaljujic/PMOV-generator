# Session T41 (layout: attribute fans, degree-scaled edge length, 13 red tests)

## The 13 initial failures
`layout.test.ts` (3): `layoutDiagramSync returns a plain object` (Radnik x Tehnicar overlap), `layoutDiagram (ELK) positions
everything without overlaps` (Radnik x Tehnicar), `specialization row constraints` (expected 2 to be 1).
`layout.integration.test.ts` (10): osnovni sync/ELK (Radnik x Rukovođenje / Odeljenje x Zapošljavanje overlap),
specijalizacija sync/ELK (expected 2 to be 1), biblioteka sync/ELK (veza too far from participants: 53.9 >= 183.3,
645.7 >= 799.7), proizvodnja sync/ELK (Artikal x NaručeniArtikal / Partner x Lokacija overlap), domeni sync/ELK
(Radnik x Rukovođenje / Odeljenje x Zapošljavanje overlap).

## Causes
1. `post.ts toPositions` computed `x = cx - w/2 - minX + MARGIN + px`: the attribute padding was added on top of a
   `minX` that already contained it, shifting each node by its own padding. Inflated boxes then overlapped and the
   spec rows (all podtipovi share one y) broke (the shift differs per node). One-line fix; cleared 7 of the 13 at once.
2. Remaining shape failures (veza far from its participants): desired edge length used the inflated sizes, so
   nodes with big attribute padding got far-away neighbours. Edge lengths now use actual sizes.
